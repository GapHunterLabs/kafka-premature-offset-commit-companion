Reports a Kafka consumer poll loop that hands records to asynchronous work (ExecutorService.submit(...), CompletableFuture.runAsync(...)/supplyAsync(...)) and commits offsets before that work has finished (no .get(), .join() or .awaitTermination() first).

The commit can be explicit (commitSync()/commitAsync()) or implicit through the default enable.auto.commit=true, which commits on the next poll(). If the process stops before the async work completes, those records are marked as consumed and never processed.
